# 战国浮生录 Sengoku Life — Playable Demo（第一章《乱世来客》）

日本战国穿越人生模拟 RPG：1560 年清洲，距桶狭间之战 16 天。结识人物、拜师学剑、在历史洪流中做出选择。一局约 20–30 分钟。

## 怎么玩

- **iPhone**：直接打开发布的 Artifact 链接即可游玩；或把 `dist/index.html` 部署到任何静态网站（Netlify / GitHub Pages / Cloudflare Pages），用 Safari 打开后“添加到主屏幕”即为 PWA。
- **本地**：`npm install && npm run build`，然后用任意静态服务器打开 `dist/index.html`（例如 `npx serve dist`）。

## 开发命令

| 命令 | 作用 |
| --- | --- |
| `npm run build` | esbuild 打包，生成单文件 `dist/index.html`（独立网站/PWA）和 `dist/artifact.html`（Claude Artifact 版） |
| `npm test` | 19 项自动测试：战斗规则、AI 风格、平衡性、修行递减、时间、日程、存档迁移、完整通关与多结局 |
| `npm run typecheck` | TypeScript 严格模式检查 |
| `npm run balance` | 战斗平衡模拟（各种策略 × 各对手 × 不同成长阶段的胜率） |
| `npm run playthrough` | 自动通关脚本，打印完整流程 |
| `node scripts/e2e.mjs <目录>` | iPhone 13 视口的浏览器验收（需 Playwright，先在 dist 起本地服务 4173 端口） |

技术选择：TypeScript + React 19 + esbuild。原计划 Vite，但开发环境无法访问 npm，故用已有的 esbuild（Vite 底层同样是它）打包；测试用 Node 内置 `node:test`。换成 Vite/Vitest 只需改构建脚本，源码不受影响。

## 架构

```
src/engine/        规则引擎（纯函数，可测试）
  combat/          剑术比试：rules 结算 · ai 对手倾向 · hint 气配/看破/考验评分
  game.ts          行动、移动、交谈、场景、比试、时间推进
  training.ts      修行：重复递减、瓶颈、突破
  save.ts          本地存档、版本迁移、存档码
  registry.ts      内容注册表（引擎只依赖接口）
src/content/       1560 清洲剧本（数据驱动）：人物、地点、行动、事件、传闻、结局
src/ai/dialogue.ts 可选 AI 对话适配器（默认未启用，AI 无权修改状态）
src/ui/            React 界面（绘卷风 SVG 插画、移动端布局）
tests/             自动测试
```

新增年份/地点/人物：在 `src/content/` 写新的场景、行动、人物数据并注册即可，无需改引擎。

## 已实现

- 开始菜单、取名、穿越开场；新游戏 / 继续 / 3 个手动档位 / 存档码导入导出 / 重置；每次行动自动存档，刷新后续玩。
- 4 个地点（清洲城下、柳心馆、茶屋水月、城外五条村），往返村庄耗时；一日三时段（朝/昼/晚），共 16 日。
- 5 位主要 NPC（柳田源斋、早瀬隼人、清兵卫、阿凉、前田又左卫门利家）+ 岩田权六、五郎作、织田信长；各有性格、心愿、日程、信任/尊敬/恩义/立场与记忆，记忆改变台词与事件。
- 剑术：进攻/防守/试探/调整；气力、架势、距离、主动、消极判罚；4 种对手风格（积极进攻、谨慎防守反击、应变、师父）；情报等级决定“气配”提示，试探可看破下一手；规则数值在按钮与战报中可见。
- 修行：素振、型稽古（重复递减）、观摩、切磋、山路奔跑、师父指导（按信任解锁，突破上限）；技法“柳返”“踏入”；清兵卫的木刀。
- 主线《乱世来客》与支线：病童、清兵卫的铺子（有期限，失败会被封）、今川细作、隼人与又左卫门的冲突、信长当街一问、师父的考验（看读局而非输赢）。
- 关键抉择（住处、初败后的态度、细作处置、茶屋冲突、劝隼人、又左卫门之约、桶狭间前夜 5 条路线），影响人物命运与结局；今川军推进是规则驱动的世界状态。
- 结局页：人物去向、足迹、下一章方向。

## 已知限制

- AI 自由对话：已搭好只读上下文与服务端代理接口，但未配置安全的服务端，所以显示为“未启用”，全部内容由固定对话完成。
- 人物“立绘”是印章式头像与原创水墨 SVG 场景，不是手绘立绘。
- 第一章内容固定为 1560 年清洲；穿越年份/身份选择只做了架构预留。
- Artifact 版中存档保存在该浏览器里；换设备或清除浏览数据会丢失，可用“存档码”备份。
- Artifact 版不支持离线 PWA；离线需用 `dist/index.html` 自行部署。
- 战斗动画较克制（只有过渡），没有招式动画和音效。

## 下一版最值得做的三件事

1. **真正的人物立绘与战斗演出**：为 5 位主角定制水墨淡彩立绘与表情差分，比试加入出刀/格挡的短动画和音效，这是沉浸感最大的短板。
2. **安全的 AI 自由对话**：用一个小型服务端代理接入模型，让玩家能和人物自由交谈；规则引擎仍是唯一能改动状态的地方。
3. **第二章与更深的剑术**：清洲同盟到美浓攻略（1561–1567），加入流派技巧树、剑豪挑战与更多会成长的对手，并开放穿越年份选择。
